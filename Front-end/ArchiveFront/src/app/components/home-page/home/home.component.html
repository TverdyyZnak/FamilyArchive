Часто задаваемые вопросы

Существуют ли ограничения в архиве?
?

Да, ограничения имеются. В зависимости от уровня подписки, будут накладываться огрничения на количество людей в архиве, на количество глав в истории каждого человека, на объем документов и тд. Со всеми ограничениями можно ознакомиться ТУТ

Файлы каких форматов можно добавить к архиву?
?

Для изображений можно использовать только файлы формата .png и .jpg. Для текстовых файлов(документов) можно использовать только файлы формата .pdf

Кто может редактировать архивы?
?

Архив может редактировать только тот, кто создал его. Гости, добавленные к архиву, смогут только посмотреть его. Также предусмотрена функция передачи прав редактора.
